# 🎮 赚钱小游戏记录工具 - 产品需求文档

## 1. Product Overview
一款用于记录和管理多个赚钱小游戏收益的现代化Web应用。帮助用户系统化地追踪游戏收益、设定目标、分析数据，让赚钱过程更高效有条理。
- 为玩家提供游戏管理、收益记录、数据分析、目标追踪等核心功能
- 打造视觉效果精致的现代化界面设计

## 2. Core Features

### 2.1 User Roles
| Role | Registration Method | Core Permissions |
|------|---------------------|------------------|
| 普通用户 | 无需注册 | 完整使用所有功能，数据本地存储 |

### 2.2 Feature Module
1. **仪表盘**: 收益概览、统计卡片、快速操作
2. **游戏管理**: 添加/编辑游戏、游戏列表、标签分类
3. **收益记录**: 记录每笔收益、提现、历史数据
4. **数据分析**: 趋势图表、收益排行、详细分析
5. **目标设定**: 目标设定、进度追踪、成就系统
6. **设置**: 主题切换、数据备份、偏好配置

### 2.3 Page Details
| Page Name | Module Name | Feature description |
|-----------|-------------|---------------------|
| 仪表盘 | 统计概览 | 显示总收益、本月收益、今日收益、活跃游戏数等关键指标 |
| 仪表盘 | 快速记录 | 一键添加新收益记录的快捷入口 |
| 仪表盘 | 最近活动 | 显示最近的收益记录和游戏活动 |
| 游戏管理 | 游戏列表 | 卡片式展示所有游戏，支持筛选和搜索 |
| 游戏管理 | 添加游戏 | 表单添加新游戏，包含游戏信息、图标、标签 |
| 收益记录 | 记录列表 | 时间线式展示所有收益记录 |
| 收益记录 | 添加记录 | 记录新的收益，选择游戏、金额、时间、备注 |
| 数据分析 | 趋势图表 | 使用Chart.js展示收益趋势、游戏排行 |
| 目标设定 | 目标管理 | 设置月度/年度目标，进度可视化 |
| 设置 | 主题切换 | 多种精美主题可选 |
| 设置 | 数据管理 | 数据导出/导入、重置功能 |

## 3. Core Process
用户打开应用 → 在仪表盘查看概览 → 点击添加游戏 → 记录游戏信息 → 产生收益时添加记录 → 查看数据统计分析 → 设置目标并追踪进度

```mermaid
flowchart TD
    A[打开应用] --> B[查看仪表盘]
    B --> C{需要添加游戏?
    C -->|是| D[游戏管理页面]
    C -->|否| E[记录收益]
    D --> E
    E --> F[查看分析数据]
    F --> G[设定目标]
    G --> B
```

## 4. User Interface Design
### 4.1 Design Style
- **主色调**: 渐变青色到粉色
- **次色调**: 暖金色、亮蓝色
- **按钮样式**: 圆角胶囊形、霓虹光晕效果
- **字体**: Poppins + Noto Sans SC
- **布局风格**: 卡片式布局，卡片带阴影和圆角
- **图标**: 使用 Lucide React 图标库

### 4.2 Page Design Overview
| Page Name | Module Name | UI Elements |
|-----------|-------------|-------------|
| 仪表盘 | 统计卡片 | 渐变背景、动态数字、悬浮动画、毛玻璃效果 |
| 游戏管理 | 游戏卡片 | 渐变色、图标、状态标签、悬浮放大效果 |
| 收益记录 | 时间线 | 垂直时间线、彩色标记、卡片悬停效果 |
| 数据分析 | 图表区域 | 渐变图表、数据卡片、交互悬停提示 |
| 目标设定 | 目标卡片 | 进度条动画、成就徽章 |

### 4.3 Responsiveness
- 移动端优先设计
- 完美适配手机、平板、桌面
- 流畅的触摸体验

### 4.4 动画与动效
- 页面加载淡入动画
- 卡片悬浮上浮效果
- 数字滚动动画
- 平滑的页面切换过渡
